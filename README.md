# מה ללבוש היום?

אפליקציית PWA שמציגה המלצת לבוש מצוירת לפי מזג האוויר הנוכחי (OpenWeatherMap).

| מצב | המלצה |
|---|---|
| טמפרטורה מתחת ל-18° | 🧶 קח סוודר |
| 18° ומעלה | 👕 שים חולצה קצרה |
| יורד גשם עכשיו, או סיכוי של 50% ומעלה לגשם ב-12 השעות הקרובות | ☂️ אל תשכח מטריה (בנוסף) |

הספים מוגדרים בראש [app.js](app.js) (`SWEATER_BELOW`, `RAIN_POP_THRESHOLD`).

## הרצה מקומית

```bash
node server.js
```

ואז לפתוח http://localhost:8080. בפתיחה הראשונה האפליקציה מבקשת מפתח API של OpenWeatherMap
(הרשמה חינם ב-https://home.openweathermap.org/api_keys). המפתח נשמר ב-localStorage של המכשיר.
אפשר במקום זה להעתיק את `config.example.js` ל-`config.js` ולשים בו את המפתח.

## התקנה בטלפון

איתור מיקום (GPS) והתקנה כאפליקציה דורשים HTTPS, לכן צריך להעלות את התיקייה לאחסון סטטי
(GitHub Pages, Netlify וכו'), לפתוח את הכתובת בטלפון ולבחור "הוסף למסך הבית".

שים לב: מפתח שמוכנס ל-`config.js` גלוי לכל מי שפותח את האתר. לשימוש אישי עדיף להזין אותו דרך מסך ההגדרות.

## אייקונים
